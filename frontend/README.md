# Frontend

Aplicación web en **Angular 22 + Angular Material** para los trabajadores de la entidad financiera.

```bash
npm install
npm start      # http://localhost:4300, con la API en http://localhost:8080
npm test       # tests unitarios con Vitest
npm run build  # compilación de producción en dist/frontend
```

Estructura, decisiones y forma de ejecutar todo el proyecto: ver el [README principal](../README.md) y la [arquitectura](../docs/02-arquitectura.md#27-frontend).
